JENDELA JASPER — BRAND ASSET STARTER KIT

Isi paket:
01_Logo: crop logo dari gambar sumber dan versi PNG transparan hasil ekstraksi, plus ikon J.
02_Color_Palette: palet warna PNG.
03_Backgrounds: latar abstrak untuk sosial media dan presentasi.
04_Templates: template raster untuk post sosial dan slide presentasi.
05_Reference: poster sumber dan papan konsep visual.

Warna rekomendasi:
Navy Blue #174C7E | Deep Blue #10365B | Orange #F5A623 | Gold #FDBB45 | Ivory #F7F1E5 | Gray #747D87

Catatan penting: file logo transparan dan ikon merupakan ekstraksi raster dari gambar poster, bukan file master vektor. Untuk produksi cetak besar, signage, atau penggunaan brand resmi, sebaiknya logo dibuat ulang/ditrace secara presisi menjadi SVG/AI/EPS dan diverifikasi ejaan serta proporsinya. Template dalam paket ini berupa JPG/PNG raster, bukan file Canva/PPTX editable.
